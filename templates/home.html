Model & Methodology

Designed with model evaluation in mind

ChurnIQ uses a Logistic Regression classification pipeline with preprocessing and class balancing. It was selected after comparing its test-set performance with a Random Forest model, with particular attention to recall and ROC-AUC.

✓ Data preparation: handles preprocessing before model prediction.
✓ Model comparison: evaluates classification metrics on a held-out test set.
✓ Interpretable analysis: displays model metrics and coefficient-based feature associations.
! Important: predictions are estimates, not guarantees. Model associations do not establish causation.
